# Renovation Walkthrough

A true-scale VR walk-through of a bathroom renovation for Meta Quest, built in Unity 6 (URP) from the client's
hand drawings so she can stand in the room before it's built and compare design options.

The project is set up following the LAVA "Quest Tutorials 2026" (Part A setup, Part C building blocks):
OpenXR with the Meta XR SDK, the Camera Rig and Teleport building blocks, and controller teleport locomotion.

## In the headset
You start just inside the door, facing north. The room is true scale, so you can also walk it physically.
- Right thumbstick forward: aim and teleport (floor and shower). Left or right: snap turn.
- Left controller X / Y: next / previous design option. A label shows which option is active.
- Hold the Meta button to recenter if you walk outside the room.

## The room (10'-6" x 10'-3", 8'-0" ceiling assumed)
- Tile: Atlas Concorde Boost Pro Cream, Taupe, Tobacco and Ivory, 120 x 120 cm large format. Tobacco on the north
  and west walls and the tub enclosure; a 14" Ivory strip behind the shower valve.
- Floor, shower floor and curb: Architessa Level Pebble.
- Tub: MTI Andrea 1 undermount in a tiled deck that continues into the shower as a bench.
- Fixtures in matte black: Kohler Parallel wall-mount bath filler and sink faucets, Parallel showerhead,
  Shift square handshower, Parallel Hotelier; chrome drains.
- Eskimo Gordon towel warmer (black), TOTO toilet, frameless LED mirrors, 15" x 72" mirrored cabinet,
  wood blinds in dark walnut with black tapes.

## Building it
Open the folder in Unity 6000.5 with Android Build Support. Everything is generated by editor scripts;
all dimensions are constants at the top of `Assets/Bathroom/Editor/BathroomBuilder.cs`, in inches
(x = east from the west wall, z = north from the south wall, y = up).
- Tools > Client Bathroom > Build Scene (room + XR rig + lighting): rebuilds everything and re-bakes the lighting.
- Tools > Client Bathroom > Build Quest APK, then install with `adb install -r Builds/ClientBathroom.apk`
  (Developer Mode on, USB debugging allowed), or use File > Build Profiles > Build And Run.
- Tools > Client Bathroom > Render Review Snapshots: stills of every option in `Builds/Snapshots`.
- Tools > Quest Setup > Run Part A Setup: reapplies the Quest project setup to a fresh project.
